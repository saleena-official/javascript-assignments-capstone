JavaScript Assignments and Capstone Project

Overview

This project contains six practical JavaScript assignments and an Interactive Product Inventory & Analytics Dashboard capstone project.

Assignments

1. Variables, Data Types, and Console Operations
2. Operators, Expressions, and Input Handling
3. Conditional Logic Implementation
4. Loop Control Structures
5. Function Architecture and Scope
6. Arrays, Objects, and Core Methods

Capstone Project

Interactive Product Inventory & Analytics Dashboard

The capstone allows users to add products, validate inputs, assign product categories, calculate total inventory value, filter affordable products, and generate formatted reports.

Technologies Used

- JavaScript
- HTML
- Browser Developer Tools and Console
- Visual Studio Code

How to Run

1. Open "test.html" in a web browser.
2. Open Developer Tools and select the Console tab.
3. Change the JavaScript filename in "test.html" to run a different assignment.
4. For the capstone, enter a product name and price when prompted.

Concepts Practiced

Variables, data types, type conversion, operators, conditions, switch statements, loops, functions, scope, arrays, objects, "forEach()", "filter()", "map()", input validation, and financial calculations.
